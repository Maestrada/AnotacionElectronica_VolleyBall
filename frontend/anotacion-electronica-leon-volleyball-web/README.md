# Cliente de prueba

Interfaz React/Vite mínima para probar la API de anotación.

1. Inicie la API en `http://localhost:60153`.
2. Ejecute `npm.cmd run dev` desde esta carpeta.
3. Abra la URL que muestre Vite. La pantalla trae esa URL de API por defecto y permite cambiarla.

Permite crear un partido no programado con los UUID de equipos, convertir una programación del calendario en partido, iniciar, anotar puntos, deshacer y confirmar cambio de cancha/cierre de set.
